# DataFrame Reporter

Проект содержит класс 'DataFrameReporter', который формирует краткий отчёт по pandas DataFrame.

Отчёт включает:
- количество строк и столбцов;
- количество и долю дубликатов;
- сводную статистику 'describe()';
- количество и долю пропущенных значений.
